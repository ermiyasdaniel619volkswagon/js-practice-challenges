FIZZBUZZ CHALLENGE
PROBLEM:
Write a program that prints numbers from 1 to 100.
Rules:
- If the number is divisible by 3, print "Fizz"
- If the number is divisible by 5, print "Buzz"
- If the number is divisible by both 3 and 5, print "FizzBuzz"
- Otherwise, print the number itself

ALGORITHM (STEP BY STEP):
1. Start
2. Create a loop from 1 to 100
3. For each number:
a. Check if the number is divisible by BOTH 3 and 5
- If yes, print "FizzBuzz"
b. Else, check if the number is divisible by 3
- If yes, print "Fizz"
c. Else, check if the number is divisible by 5
- If yes, print "Buzz"
d. Else
- Print the number
4. End loop
5. Stop


NOTE:
Always check divisibility by both 3 and 5 FIRST.
